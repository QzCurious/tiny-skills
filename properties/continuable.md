# Continuable

## Meaning

`Continuable` 是主題的一種 Property: 其原始意圖, 有效的接續方式與可能的終止狀態，皆可在不發生實質扭曲的情況下還原

## Applies To

適用於需要跨時間, 對話, Agent 或其他處理邊界延續的主題。主題可以是文件, 溝通主題, 任務或其他持續中的關注事項

## Satisfaction

一個主題至少應能可靠還原:

- 原始意圖
- 如何有效繼續
- 可能的終止狀態

還原後的理解不得使後續工作產生實質扭曲

## Boundaries

`Continuable` 不要求保存完整對話或 activity history, 不要求主題已經 resolved 或 Well-Specified, 也不規定任何持久化或 Artifact Carrier
