# Continuable

## Meaning

`Continuable` 是一個主題相對於 Continuation Scenario 的一種 Property: 在預期的暫停或交接邊界後, 接續者仍能從屆時可取得的脈絡理解主題的 Orientation, 還原其 Continuation State, 並在不發生實質扭曲的情況下繼續 Intended Work

## Applies To

適用於需要跨時間, 對話, Agent, ownership 或其他處理邊界延續的主題。主題可以是溝通主題, 任務, 調查, 文件, 設計工作或其他持續中的關注事項

## Evaluation Context

Continuable 必須相對於明確或可合理推定的 Continuation Scenario 判斷。同一個主題可以對同一 Agent 的新 Thread 成立, 但不足以支援另一個 Agent, 團隊或無法取得相同脈絡, capabilities 或 permissions 的環境

Continuation Scenario 中只有會實質改變所需 state, materialization 或 continuation reliability 的條件需要被明確建立; 可由邊界後穩定脈絡可靠推定的部分不要求重述

## Satisfaction

對 Continuation Scenario 而言, 邊界後仍可取得的脈絡應足以使接續者先建立 Orientation 所需的理解, 再可靠還原 Continuation State, 判斷其目前仍然有效, 並在不改變主題實質意義與 governing framing 的情況下繼續 Intended Work

當還原後的理解會誤認 subject, current motivation, intended outcome 或 material scope, 誤認目前有效的方向或內容, 遺漏會影響接續的 material Unresolved, 誤認其 resolution status 或已知 resolution path, 恢復已失效方向, 或使接續者採取不再有效的 action 時, 即構成 material distortion

當 Continuation State 中內容的 status, applicable authority 或 material provenance 被誤認, 且因此改變有效 framing, 允許行動或必要 alignment 時, 也構成 material distortion

## Boundaries

`Continuable` 不要求主題已 resolved, 對最終目標 Well-Specified, self-contained, 或每個 Unresolved 都已有有效 resolution path

未知事項, 多個候選方向或 blocker 本身不違反此 Property; 只要其目前狀態, 影響與已知的有效接續方式可以可靠還原

依賴接續者無法取得的 private memory, temporary context, history, capability 或 permission, 不能使主題對該 Continuation Scenario 成立 Continuable

`Continuable` 不規定固定 heading, schema 或 persistence mechanism。對一項 Continuation Scenario 成立, 不表示對所有接續情境皆成立
