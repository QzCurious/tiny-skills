# Clear Reading Path

## Meaning

`Clear Reading Path` 是結構化內容的一種 Property: 對預期讀者與用途而言, 內容提供連貫的主要理解路徑, 使讀者能從合理起點逐步建立後續所需的脈絡與概念關係, 而不必因先備脈絡安排不當而反覆回頭重新解讀

## Applies To

適用於組織方式會影響理解過程的結構化內容, 例如 Skill, source file, specification, README 或其他說明性內容

## Satisfaction

具有 Clear Reading Path 的內容應使預期讀者能:

- 辨識合理的閱讀起點與初始理解框架
- 在需要某項脈絡或概念時, 已由先前內容, 合理的既有知識或足夠接近的內容取得
- 理解相關內容之間的關係, 而不需要不必要地切換脈絡或重新解讀
- 在存在 supporting detail, reference 或其他支線時, 仍能辨識並持續主要理解路徑

必要的 cross-reference, 回看或非線性閱讀不違反此 Property; 問題在於因缺少或安排不當的先備脈絡而造成可避免的 conceptual backtracking

## Boundaries

`Clear Reading Path` 不等同於簡短, 簡單, self-contained, chronological order, source order, execution order, 單一線性順序或固定 outline

此 Property 不規定特定實踐方法; 不同內容可以透過 grouping, ordering, locality, hierarchy, orientation, reference 或其他方式建立 Clear Reading Path
