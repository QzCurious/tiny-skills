# Clear Reading Path

## Meaning

`Clear Reading Path` 是結構化內容的一種 Property: 其組織方式讓預期讀者能依理解所需逐步建立脈絡與概念關係，而不需要不必要地回頭重新解讀先前內容

## Applies To

適用於具有可組織閱讀順序的結構化內容，例如 Skill, source file, specification, README 或其他說明性內容

## Satisfaction

內容的組織應讓:

- 後續內容所需的 orientation 與概念脈絡在需要前已足夠建立
- 有理解依賴的概念依其關係形成連貫的閱讀順序
- 需要共同理解的相關內容具有足夠 locality
- 讀者不必因缺少先備脈絡而反覆回頭重新解讀

## Boundaries

`Clear Reading Path` 不等同於簡短, 簡單, chronological order, source order, execution order 或固定 outline。必要的 cross-reference 或回看本身不違反此 Property; 問題在於可避免的 conceptual backtracking

此 Property 不規定特定實踐方法; 不同 Skill 或內容類型可以用不同方式建立 Clear Reading Path
