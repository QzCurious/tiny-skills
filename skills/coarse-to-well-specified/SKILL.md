# Coarse to Well-Specified

先辨識 Intended Work: 目標目前要支援的下一個有界工作範圍。Intended Work 必須足以判斷哪些資訊與選擇會實質影響此次細化, 以及目標需要明確到什麼程度; 不以猜測固定會改變所需明確程度, 允許結果或工作邊界的 interpretation

使目標對 Intended Work 達到 `Well-Specified`, 同時保留 User 的原始方向

先辨識並固定原始方向。把已知內容與可由脈絡合理推得的內容轉成明確陳述, 補足 Intended Work 所需的意圖, 預期結果, 邊界, 限制, 重要假設與影響; 將推論標示為假設

只展開到 Intended Work 能可靠進行所需的程度。當多個合理理解會導向實質不同的結果, 且 applicable authority 尚未使其中一項成為 governing interpretation 時, 不自行選擇; 將真正需要建立的 condition 保持 explicit, 並依運作模型在受影響的 Governed Action 前建立 readiness

產出一份連貫的明確說明, 區分已確定內容, 採用的假設與仍待決事項。當 Intended Work 能沿原始方向可靠進行, 且執行者不需自行補足會實質改變結果的解讀時, 即完成此 Skill。若仍有未決事項阻礙原 Intended Work, 只能將目標視為足以支援釐清該事項, 不得宣稱它已對原 Intended Work 達到 Well-Specified
