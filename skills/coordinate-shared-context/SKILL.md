# Coordinate Shared Context

使用 `Maintain Continuable Context` 維護主題有意義且 Continuable 的 current state。

辨識誰會建立、修改或依賴這些 Context Artifacts，以及 artifacts 的 authority、current-state surface 與必要的 history surface，並將這些協作需求納入 Artifact Carrier 的選擇。

更新前，先調和 concurrent changes、既有決策、未解分歧與實質不確定性。建立 Context Artifact 或改變其他人可依賴的 current state 前，使用 `Align Intent` 對齊預定變更。

將 current-state surface 維持為最新且已對齊的主題說明。只有當 attribution、被否決的替代方案、變更理由或其他 process history 仍會實質影響解讀或後續協作時，才將其保留於 history surface；若 carrier 沒有分離的 surfaces，在其中建立等效區分。

當後續接手或共同工作的人能還原 current state 與有效的繼續方式，且不會把未解或已被取代的主張視為 settled facts 時，即完成共享協調。
