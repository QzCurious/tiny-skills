# Clear Reading Path

## Meaning

`Clear Reading Path` 是結構化內容的一個 Predicate: 對預期讀者與用途而言, 內容提供連貫的主要理解路徑, 使讀者能從合理起點逐步建立後續所需的脈絡與概念關係, 並能沿著已建立的理解繼續閱讀, 而不必因先備脈絡缺失, 關係安排不當或不必要的概念跳躍而反覆回頭重新解讀

## Applies To

適用於組織方式會影響理解過程的結構化內容, 例如 Skill, source file, specification, README 或其他說明性內容

## Satisfaction

具有 Clear Reading Path 的內容應使預期讀者能:

- 辨識合理的閱讀起點與初始理解框架
- 在需要某項脈絡或概念時, 已由先前內容, 合理的既有知識或足夠接近的內容取得
- 理解相關內容之間的關係, 而不需要不必要地切換脈絡或重新解讀
- 在主要理解路徑上的 section entry, transition 或 instruction 中, 能以上文已建立的脈絡理解其作用與接下來要處理的內容, 而不必自行補回被省略的概念關係
- 在存在 supporting detail, reference 或其他支線時, 仍能辨識並持續主要理解路徑

必要的 cross-reference, 回看或非線性閱讀不違反此 Predicate; 問題在於因缺少或安排不當的先備脈絡, 概念關係或 transition 而造成可避免的 conceptual backtracking

## Boundaries

`Clear Reading Path` 不等同於簡短, 簡單, self-contained, chronological order, source order, execution order, 單一線性順序或固定 outline

`Clear Reading Path` 也不要求每個句子本身簡單或低複雜度。若理解困難主要來自局部措辭, 語法, 命名或抽象程度, 而非所需脈絡, 概念關係或閱讀路徑的安排, 不屬於此 Predicate 本身所描述的問題

此 Predicate 不規定特定實踐方法; 不同內容可以透過 grouping, ordering, locality, hierarchy, orientation, explicit transition, reference 或其他方式建立 Clear Reading Path
